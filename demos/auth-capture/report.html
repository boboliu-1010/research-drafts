源码与工具链

官方合约测试 112 项通过，其中 94 项 fuzz 测试共 24,064 轮；排除了上游 Base 主网 fork 集成测试。合约用 Solidity 0.8.28 重新编译，与链上代码比较时归一化了构造时写入的 immutable。Escrow 和 TokenStore 模板完整 runtime 匹配；三个 Collector 需要额外去掉末尾的 CBOR 编译元数据。

Foundry v1.8.5 有一个 Permit2/ERC-6492 用例失败，官方 CI 的 v1.3.6 全部通过。TypeScript SDK 单测和 HTTP 端到端流程还未运行。
